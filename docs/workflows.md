# Workflows and current limits

## Plan and export a service

Create an empty service with a name, date, and time. Add songs, a reading, sermon, slides, or a placeholder for a visitor's presentation. Each service can use different songs and sermon points. Download the .praiseav file and open it in PraiseAV Windows. Songs without words are exported as a visible reminder to add licensed words in PraiseAV. Presentation placeholders contain a filename reminder, not the actual PowerPoint or video file.

The Suite's cue and slide view is a local preview. It does not change the congregation projector. The desktop program handles live output. A shared OneDrive or Google Drive folder may transfer files between computers after the church has set it up; downloading a file in the Suite does not by itself place it in that folder.

## Songs and musicians

The Suite can store church-licensed lyrics and ChordPro charts, show a transposed preview, and export a plain text song that PraiseAV can import. The complete service export carries ChordPro alongside words. The same song can have a different key and section order in each service. PraiseAV uses those choices for slides and band printouts without changing the library copy. The Band stand works on phones and tablets: choose a service, move between songs by buttons or swiping, choose a sounding key and capo, and print or save a songbook through the browser's print dialog. Personal key and capo choices do not change the service plan.

SongSelect and modern Bible translations may require the church's own licences. The Suite does not supply them. The sample leaves modern worship song lyrics and modern translation text empty.

## People, rotas, groups, rooms, giving

The People area stores contact details, blockout dates, and pastoral notes for authorised staff. Service rotas record assignments and status. The planner sees warnings for blockout dates and same-day double assignments before adding a volunteer; an override requires confirmation. New assignments start Pending. Volunteers do not yet have an accept/decline button linked to their own account. Groups and rooms have basic records and a local overlap check for new bookings. The giving area records transactions for finance review. These are planning and record tools; automatic notifications, volunteer self-service acceptance, a payment processor, and HMRC submission are not implemented.

## Children and public alerts

Kids staff can record check-in and check-out, pickup codes, and medical notes. A public pager reference is separate from the pickup verification code. Parent page text can be copied to the PraiseAV desktop alert control. The Suite does not send it automatically and cannot verify who collects a child; staff must do so in person.

## Offline use

PraiseAV Windows runs independently and offline. The Suite sample works without an account but does not persist changes between visits. Church mode needs a connection to Firebase to sign in and save shared records. Download backups regularly.
